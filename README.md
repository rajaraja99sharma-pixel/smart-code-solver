# 🚀 Smart Code Solver

Smart Code Solver is a MERN Stack based coding platform inspired by LeetCode. Users can register, log in, solve coding problems, run code, submit solutions, and track solved problems.

## ✨ Features

* User Authentication (Signup/Login)
* JWT Based Authorization
* Problem Management System
* Code Editor
* Custom Input Support
* Code Execution
* Problem Submission Tracking
* Solved Problem Status (✔️)
* Admin Panel for Managing Problems
* MongoDB Database Integration

## 🛠️ Tech Stack

### Frontend

* React.js
* React Router
* Axios
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

## 🚀 Installation

### Clone Repository

git clone https://github.com/rajaraja99sharma-pixel/smart-code-solver.git

### Install Dependencies

Frontend:

cd client

npm install

Backend:

cd server

npm install

### Run Application

Backend:

npm start

Frontend:

npm start
